# .github

Organization-wide defaults for **Veridium-Global**:

- `profile/README.md`: the public organization profile.
- Community health files (`SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SUPPORT.md`) and issue / pull request templates. GitHub applies them to every repository in the organization that does not have its own version.

Changes go through pull requests reviewed by an organization owner.
